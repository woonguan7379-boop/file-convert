# 每日钱包 · 自动记账 + 每日额度

一个单文件网页 App（`index.html`），给 iPhone 用：

- **自动抓取交易**：Apple Pay 付款（全自动）、TNG / PayNow 等任何 App 付款成功页（轻点背面三下截图识别）、银行短信/邮件，iPhone 快捷指令自动把交易送进 App
- **新马自动切换**：自动识别每笔交易是 RM 还是 S$（PayNow→新币，TNG/DuitNow→马币），按实时汇率换算成收入货币扣额度；用定位 / 最近交易 / 时区判断你现在在哪国，首页用当地货币显示
- **钱包充值不算消费**：用卡充值 TNG 等会被识别并忽略，避免重复计算
- **今天还能花多少**：每笔消费立刻从今日额度扣掉；今天省下的钱分到后面几天，超支了明天额度自动变少
- **必要 / 想要 / 不必要**：自动记账后弹窗，点一下就分好类
- **分析与建议**：钱花在哪、花得快不快、哪些钱可以省（奶茶外卖、深夜消费、订阅、小额消费……）
- **数据只存在你手机的 Safari 里**，不上传任何服务器；可以备份 / 导出 CSV

## 每日额度怎么算

```
每月可自由花 = 月收入 − 固定支出 − 每月存款
今日额度    = (每月可自由花 − 本周期今天之前已花) ÷ 本周期剩余天数（含今天）
今天还能花  = 今日额度 − 今天已花
```

固定支出（房租等）已经预留，不扣每日额度；退款会加回额度；收入不影响额度。

## 第一次使用

1. **开启 GitHub Pages**：仓库 Settings → Pages → Source 选 *Deploy from a branch* → Branch 选 `claude/personal-finance-app-mkavvj`、目录 `/ (root)` → Save。
   一两分钟后网址就是：`https://woonguan7379-boop.github.io/file-convert/`
2. 用 **Safari** 打开这个网址 → 分享 → 添加到主屏幕，**关掉「作为 Web App 打开」**（否则桌面图标的数据和快捷指令打开的 Safari 是分开的，App 会显示警告）。
3. 在「设置」里填写月收入、发薪日、存款目标和固定支出。
4. 按「设置 → 自动记账设置」里的步骤，在快捷指令 App 中设置自动化。

## 快捷指令传参格式

| 用途 | 网址 |
|---|---|
| 银行短信/邮件 | `…/file-convert/#sms=<URL 编码后的短信内容>` |
| 截图识别 | `…/file-convert/#ocr=<URL 编码后的截图文字>` |
| Apple Pay | `…/file-convert/#src=pay&add=<金额>&m=<URL 编码后的商家>` |
| 快速记现金 | `…/file-convert/#src=cash&add=<金额>`（可加 `&cur=SGD`） |

汇率来自 frankfurter.app / open.er-api.com（每 12 小时更新，失败时用估计值，可手动修改）。参数放在 `#` 后面，不会发送给 GitHub 服务器。同一条短信不会重复记账；短信和 Apple Pay 在 5 分钟内通知同一金额只记一次。
